# Deployment Guide — Identity Architecture

1. Go to **Archive → Integrations** in InFLOW OS.
2. Click **"Push to GitHub"** — the system will create the repository under your GitHub account automatically.
3. Verify all root files and directories are present.
4. Confirm CODEOWNERS matches your GitHub username.
