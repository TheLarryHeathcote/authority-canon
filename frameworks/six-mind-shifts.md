# Framework — Six Mind Shifts®

## Definition
A sequential internal upgrade path moving from reactive survival states to grounded, identity-driven presence.

## Components
1. **Needs:** Desperation → Protection
2. **Beliefs:** Doubt → Conviction
3. **Values:** Compromise → Clarity
4. **Roles:** Order Taker → Trusted Advisor
5. **Vision:** Present Focus → Future Casting
6. **Legacy:** Transaction → Transformation

## Application
Used for personal identity audits and internal state calibration before high-stakes interactions. Prevents reactive decision-making.

## What It Replaces
Ad-hoc motivation, tactical scripting, and surface-level mindset coaching.

## Downstream Use
Core teaching module for coaching programs, book architecture, and keynote content.
