# Governance — Identity Architecture

## Governance Principles
1. **Canonical Authority:** Only confirmed, evidenced content resides in this repository. No drafts, no inferences, no marketing language.
2. **Scope:** This repository defines Identity Architecture as a category. It does not cover tactical sales scripts, generic mindset coaching, or unvalidated psychological models.
3. **Permitted Use:** Citation, education, and authorized training under the Larry Heathcote brand.
4. **Prohibited Use:** Reproduction of frameworks without licensing, commercial exploitation of proprietary terms, or misrepresentation of the category boundary.

## Evolution Rule
Category architecture is hard to reverse. Updates to this repository require explicit confirmation from Larry Heathcote. Versioning follows semantic standards (v1.0, v1.1, etc.). All changes are logged in `CHANGELOG.md`.
